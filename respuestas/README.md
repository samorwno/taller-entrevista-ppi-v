# Respuestas del taller

Aquí se guardan los archivos `.json` que crea el botón **Guardar en GitHub** de
la página.

- Un archivo por navegador y proyecto: `<proyecto-o-equipo>-<id>.json`.
- Cada guardado hace un commit; el historial de git conserva las versiones.
- El repositorio es público. **No guardes datos personales** de estudiantes,
  docentes ni familias.

Para cargar una respuesta desde la página, usa **Cargar de GitHub**. También se
puede descargar el archivo y usar **Recuperar respaldo**.
